# Match de Intereses

Proyecto académico del SENA inspirado en la dinámica de Tinder. La propuesta conecta personas mediante intereses, habilidades y objetos personales, sin enfocarse necesariamente en relaciones románticas.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Imágenes propias en formato JPG, PNG o WebP

## Estructura

```text
tinder-sena/
├── index.html
├── README.md
├── css/
│   └── styles.css
├── js/
│   └── app.js
└── assets/
    └── images/
        ├── guitarra.jpg
        └── libro.jpg
```

## Uso

1. Agrega las imágenes propias dentro de `assets/images/`.
2. Conserva los nombres usados en `js/app.js` o actualízalos allí.
3. Abre `index.html` en el navegador.

## Nota

No se deben usar fotos o datos personales de otras personas sin su autorización.
